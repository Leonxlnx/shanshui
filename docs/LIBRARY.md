## pine.js  (56 KB)

Pines and conifers in the shan shui manner (see docs/STYLE.md).

Usage
-----
  import { makePine, paintPine, buildPine, paintConifer, paintTreeLine, makeTreeLine } from '../lib/pine.js';

  // 1. a hero pine as its own swaying texture card
  const pine = makePine(api, { x: 60, y: 640, height: 620, lean: 10, bend: 70, reach: 0.8, seed: 3 });
  layers.push(pine.layer({ z: 1 }));          // card with sensible sway already set
  // pine.anchor = { base:[x,y], top:[x,y], canopy:{x,y,r}, bbox:[x0,y0,x1,y1], reach, pads:[...] }

  // 2. paint several elements into one bake (design px, absolute coordinates)
  const src = api.bakeCanvas(1920, 1080, (ctx) => {
    paintPine(ctx, { x: 1840, y: 420, height: 380, lean: -12, bend: -55, reach: -0.9, seed: 7 });
    paintTreeLine(ctx, [[900, 330], [980, 300], [1060, 340]], { height: [26, 48], tone: 0.35, seed: 2 });
    paintConifer(ctx, 400, 600, 70, { kind: 'fir', tone: 0.1, seed: 5 });
  });
  layers.push(api.tex(inkify(api, src), { rect: [0, 0, 1920, 1080] }));

Coordinates are design px, y down. Angles are degrees measured from vertical-up, positive =
toward the right (lean 20 tilts right, bend -60 curls the trunk over to the left).
Everything is deterministic in `seed`.

## peaks.js  (48 KB)

Huangshan-style granite pillar peaks and layered far ranges, painted with
Canvas2D brushwork and finished with a GPU wet-ink pass.

The painters draw in COLOUR into any Canvas2D context in design px: each
column is first filled with the paper colour (so it occludes whatever was
painted behind it, exactly like mist separating depth planes), then inked
(shadow-side washes, lit spindle faces with fissure contours, wet blots,
crown foliage and ridge trees), and its base dissolves into billowy mist.
Paint back to front.

  import { paintPeak, paintRange, makePeaks, makeRange, wetInk } from '../lib/peaks.js';

  // one baked card holding several clusters (back to front), with anchors:
  const mid = makePeaks(api, {
    rect: [500, 100, 900, 800],                    // bake area in design px (optional)
    peaks: [
      { x: 780, top: 190, base: 560, width: 260, cols: 3, tone: 0.18, seed: 1 },
      { x: 960, top: 490, base: 820, width: 200, shape: 'mesa', clearTop: true, seed: 2 },
    ],
  });
  layers.push(mid.layer({ z: 2.5 }));            // = api.tex(mid.src, { rect: mid.rect, z })
  mid.anchors.tops   -> [{ x, y, w, flat }]        (summit points; flat tops for pavilions)
  mid.anchors.ledges -> [{ x, y, side }]           (step ledges on the column sides)

  // a pale far range card:
  const far = makeRange(api, { x0: -200, x1: 2100, base: 520, top: 260, tone: 0.78, soft: 2.5, seed: 4 });
  layers.push(far.layer({ z: 8 }));

  // or paint into your own bake and finish it yourself:
  const src = api.bakeCanvas(w, h, (ctx) => { ctx.translate(-x0, -y0); paintPeak(ctx, {...}); paintPeak(ctx, {...}); });
  const card = wetInk(api, src, { variant: 'plain' });

Peak options (paintPeak): see PEAK_DEFAULTS below. Range options: RANGE_DEFAULTS.
Variants: 'plain' | 'golden' (warm paper, warm ink, gold haze) | 'night' (greyer faces)
          | 'snow' (white caps and ledges, dark streaks, snow-topped trees).
Everything is deterministic in `seed` (or a passed api.rng `rng`).

## architecture.js  (84 KB)

Architecture painted like ink-and-colour on rice paper: pavilions, temple halls,
gates, ruined watchtowers, stone arch bridges and rope bridges.

Every painter draws into a Canvas2D context in DESIGN px (so a scene can paint
several elements into one bake) and returns anchor points. All randomness comes
from `seed` (deterministic). Common options for every painter:
  seed   : number|string   variation seed (default 1)
  fade   : 0..1            atmospheric distance: inks and reds fade toward the paper
  paper  : [r,g,b]         paper colour the fade mixes toward (default PAPER)
  snow   : bool            snow on roofs / ledges (white roofs, dark eave lines)
Buildings are modelled as simple 3D solids (rectangular plan) seen in a slight
3/4 view and painted face by face: dark tiled roofs with upturned eaves, ridge
finials, vermilion columns, pale walls, railings, stone platforms.

Painters (all return anchors in design px):
  paintPavilion(ctx, {x, y, w, tiers=2, turn=-1.1, aspect=1.25, bays=[3,2], railing=true, ...})
      (x, y) = bottom centre of the stone base, w = lower eave span (px).
      -> { base:[x,y], top:[x,yFinial], left:[x,y], right:[x,y], floorY, k }
  paintHall(ctx, {x, y, w, tiers=1, turn=0.45, aspect=2.2, bays=[5,2], door=true, steps=true, gable=true, railing=false, ...})
  paintTemple(ctx, {x, y, w, turn, snow, side=true, terrace=true, stairs:'front'|'left'|'right', mirror=false, ...})
      main hall + side hall(s) + terrace with stone balustrade + stairs.
  paintGate(ctx, {x, y, w, turn=-0.25, ...})       open gate pavilion with red posts, double lintel, low railing.
  paintTower(ctx, {x, y, w, h, side=1, ruin=0.6, windows=2, annex=true, overgrow=0.6, ...})
      ruined stone watchtower, (x, y) = bottom centre, w = width incl. side face.
  paintArchBridge(ctx, {x0, x1, y, deck, hump, arches:[{c, span, crown}], ...})
      stone arch bridge, y = water/footing line; arches c = centre x (px), span (px), crown y (px).
  paintRopeBridge(ctx, {a:[x,y], b:[x,y], sag, hand, spacing, figure, ...})
      sagging rope walkway between two anchor points (deck ends).

Baking helpers:
  bakeArch(api, rect, (ctx) => { paintX(ctx, ...); ... }, {scale=2, blur, edge, granulation, bleed})
      -> texture source covering rect [x,y,w,h] (design px), softened + inkified.
  makeArch(api, kind, opts, bakeOpts) -> { src, rect, anchors }  (kind: 'pavilion'|'hall'|'temple'|'gate'|'tower'|'archBridge'|'ropeBridge')
      picks a tight rect automatically; use api.tex(src, { rect, z }).

Example:
  import { makeArch } from '../lib/architecture.js';
  const pav = makeArch(api, 'pavilion', { x: 277, y: 470, w: 150, seed: 3 });
  layers.push(api.tex(pav.src, { rect: pav.rect, z: 1.2 }));
  // several far pavilions in one bake:
  const far = bakeArch(api, [600, 150, 1200, 500], (ctx) => {
    paintPavilion(ctx, { x: 760, y: 245, w: 36, fade: 0.35, seed: 1 });
    paintPavilion(ctx, { x: 1070, y: 320, w: 50, fade: 0.2, seed: 2 });
  });
